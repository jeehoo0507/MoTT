# 평가 기록

보고서의 모든 수치는 이 폴더의 평가 기록에서 계산하였다. 기록은 평가가 끝날 때마다 자동으로 저장·push되었으며, 손으로 고친 값은 없다.

**파일 이름:** `<날짜>/<모델>/eval/eval_<종류><크기>_<번호>__<방법>.json`
- 종류: `pcb`, `pkg`(패키지형), `ip`(인터포저형) / 크기: 10, 16, 20 (N×N 판)
- 모델 이름의 `lo_<종류>_`는 그 종류를 학습에서 제외한 모델, `_s1`·`_s2`는 seed, `+rep4`는 검증 하네스(수리 최대 4회) 적용
- 최종 모델은 `r2pk`(MoTT + P1 피크 보정), 좌표 입력 모델은 `r0`

**한 파일의 주요 항목**

| 항목 | 뜻 |
|---|---|
| `ok` | 문제마다 정밀 검사 통과 여부 |
| `count` | 문제마다 사용한 decap 수 |
| `worst` | 가장 나쁜 주파수에서의 임피던스 / 목표 임피던스 |
| `sec_per_inst` | 문제당 시간 (초) |
| `git`, `time` | 평가에 쓴 코드 커밋과 평가 시각 |

**폴더**
- `2026-10-28/`, `2026-10-29/`, `2026-11-07s2/`: 학습한 모델별 평가 기록
- `pool_v1/`: 학습 문제 목록 (평가 문제는 `scripts/build_pools.py`가 고정 seed로 다시 만든다)
- `speed_*/`, `pool_speed/`: 속도 측정 기록과 측정 문제
- `repair10/`, `repair16/`, `rulestart10/`, `s2base/`: 검증 하네스와 보조 평가
- `zs_chip/`: 칩형 판에 대한 추가 평가
- `analysis/`: 원인 분석 실험의 출력

집계는 `python scripts/collect_results.py`로 [`docs/RESULTS.md`](../docs/RESULTS.md)를 다시 만든다.
